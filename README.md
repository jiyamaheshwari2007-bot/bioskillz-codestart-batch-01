# BioSkillz CodeStart — Python Foundations Bootcamp

This repository contains my exercises, practice scripts, and weekly assignments for the **BioSkillz CodeStart — Python Foundations Bootcamp**.

## Repository Structure

- `jiya_task_01.py` — **Week 1**: Exercises 1–3 and Tasks 1–5 (variables, input/typecasting, operators, expressions, and boolean checks).
- `jiya_task_02.py` — **Week 2**: Exercises 1–3 and Tasks 1–5 (string indexing/slicing/methods, debugging, student grader, f-strings, conditionals, and nested `if` statements).

## Topics Covered

- **Week 1:** Variables, `input()`, `int` / `float` typecasting, arithmetic & compound assignment operators, f-strings, and comparison/logical expressions.
- **Week 2:** String indexing, slicing, `.strip()`, `.lower()`, `.upper()`, `.title()`, `.count()`, `.find()`, `.endswith()`, `.isdigit()`, `if / elif / else`, and nested conditions.

## How to Run

Run any script from the terminal:

```bash
python jiya_task_01.py
python jiya_task_02.py
